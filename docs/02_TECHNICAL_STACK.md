# Technical Stack

## Backend
- Node.js (16+)
- TypeScript
- NestJS / Express.js

## Frontend
- Next.js (React-based)
- TailwindCSS
- TypeScript

## Database
- MongoDB (Docker)
- Collections: users, roles, transactions, routing_rules, settlements, audit_logs

## Caching
- Redis (Docker)

## Messaging
- Optional: RabbitMQ (Docker) for async events

## Authentication
- JWT tokens
- RBAC roles: Admin, Operations, Auditor, Developer

## Observability
- Prometheus (optional)
- Grafana (optional)
- Structured logs (Winston or Pino)

## Infrastructure
- Docker Compose for local deployment
