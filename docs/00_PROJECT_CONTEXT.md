# Project Context - FinSwitch Payment Switch Simulator (Local Deployment)

## Product Overview

FinSwitch is a FinTech Payment Switch Simulator that replicates real-world payment networks like Visa and Mastercard. 
The system allows developers, architects, and fintech engineers to simulate end-to-end transaction flows including:

- Merchant API requests
- Payment routing
- Issuer authorization
- Settlement processing
- Reconciliation
- Admin portal for operations

## Goal

Provide a **complete local development platform** demonstrating distributed microservices architecture, admin portal, observability, and RBAC-based user management.

## Key Stakeholders

- Solution Architects
- Developers
- FinTech Engineers
- Platform Administrators
- Recruiters (portfolio evaluation)

## Project Scope

- Local deployment using Docker Compose
- Microservices in Node.js + TypeScript
- Admin portal using Next.js + Tailwind
- MongoDB as primary database
- Redis for caching
- All APIs documented in OpenAPI (YAML)
